線形代数

最適化を学ぶための基礎となるベクトル、行列、内積、固有値、正定値性を整理します。

ベクトルと内積

ユークリッド空間 \(\mathbb{R}^n\) において、二つのベクトル \(x,y\in\mathbb{R}^n\) の内積は

\[ \langle x,y\rangle = x^\top y = \sum_{i=1}^{n}x_i y_i \]

で定義される。内積は距離、角度、勾配、射影などを定義するための基本的な道具である。

トレース

正方行列 \(A=(a_{ij})\) のトレースは

\[ \operatorname{tr}(A) = \sum_{i=1}^{n} a_{ii} \]

で定義される。

重要な性質

\[ \operatorname{tr}(A+B) = \operatorname{tr}(A) + \operatorname{tr}(B) \]

\[ \operatorname{tr}(AB) = \operatorname{tr}(BA) \]

\[ \operatorname{tr}(A) = \sum_{i=1}^{n} \lambda_i \]

（固有値の和）

ノルム

ベクトル \(x\) のユークリッドノルムは

\[ \|x\| = \sqrt{x^\top x} \]

で定義される。最適化では、勾配ノルム \(\|\nabla f(x)\|\) が停止条件としてよく使われる。

Frobeniusノルム

行列 \(A=(a_{ij})\) の Frobeniusノルムは

\[ \|A\|_F = \sqrt{ \sum_{i,j} a_{ij}^2 } \]

で定義される。

また

\[ \|A\|_F^2 = \operatorname{tr}(A^\top A) \]

が成り立つ。

固有値と固有ベクトル

行列 \(A\in\mathbb{R}^{n\times n}\) に対して、

\[ Ax=\lambda x \]

を満たす \(\lambda\) を固有値、 \(x\neq0\) を固有ベクトルという。

固有値は

\[ \det(A-\lambda I)=0 \]

を解くことで求められる。

レイリー商

対称行列 \(A\in\mathbb{R}^{n\times n}\) に対して、 レイリー商は

\[ R(x) = \frac{x^\top A x} {x^\top x} \]

で定義される。

対称行列の場合、 レイリー商の最大値・最小値はそれぞれ 最大固有値・最小固有値に一致する。

\[ \lambda_{\min} \le R(x) \le \lambda_{\max} \]

正定値性

対称行列 \(A\) が正定値であるとは、任意の \(x\ne 0\) に対して

\[ x^\top A x > 0 \]

が成り立つことをいう。 正定値性は二次形式や凸性、ニュートン法の解析で重要になる。

対角化

行列 \(A\) が

\[ A=PDP^{-1} \]

と表せるとき、 \(A\) は対角化可能という。

ここで \(D\) は固有値を並べた対角行列である。

対角化により \(A^k\) や \(\exp(A)\) の計算が容易になる。

対称行列

\[ A^\top=A \]

を満たす行列を対称行列という。

性質

・固有値はすべて実数

・直交対角化可能

\[ A=Q\Lambda Q^\top \]

二次形式

対称行列 \(A\in\mathbb{R}^{n\times n}\) に対して

\[ q(x)=x^\top A x \]

を二次形式（Quadratic Form）という。

例えば

\[ A= \begin{pmatrix} 2 & 1\\ 1 & 3 \end{pmatrix} \]

のとき

\[ q(x) = 2x_1^2 + 2x_1x_2 + 3x_2^2 \]

となる。

二次形式と正定値性

行列 \(A\) が正定値であることは

\[ x^\top A x > 0 \qquad (\forall x\neq0) \]

と同値である。

同様に

\[ x^\top A x \ge 0 \]

が任意の \(x\) に対して成立するとき、 \(A\) を半正定値行列という。

最適化ではヘッセ行列の正定値性判定や凸性判定で頻繁に用いられる。

二次形式と固有値

対称行列 \(A\) の最小固有値と最大固有値を

\[ \lambda_{\min}, \lambda_{\max} \]

とすると、 任意の \(x\neq0\) に対して

\[ \lambda_{\min}\|x\|^2 \le x^\top A x \le \lambda_{\max}\|x\|^2 \]

が成立する。

特に

\[ \lambda_{\min}>0 \]

ならば \(A\) は正定値である。

歪対称行列

\[ A^\top=-A \]

を満たす行列を歪対称行列という。

性質

対角成分はすべて0

\[ x^\top A x = 0 \]

が任意の \(x\) に対して成立する。

スペクトル分解

対称行列 \(A\) は

\[ A = Q\Lambda Q^\top \]

と表せる。

ここで

\[ Q^\top Q=I \]

であり、 \(\Lambda\) は固有値を並べた対角行列である。

これをスペクトル分解という。

対称行列の解析や正定値性の判定で頻繁に用いられる。

QR分解

任意の行列 \(A\) は

\[ A=QR \]

と分解できる。

ここで

\[ Q^\top Q=I \]

であり、 \(Q\) は直交行列、 \(R\) は上三角行列である。

QR分解は数値計算や最小二乗問題で重要である。

極分解

正則行列 \(A\) は

\[ A=QP \]

と表せる。

ここで

\[ Q \]

は直交行列、

\[ P = (A^\top A)^{1/2} \]

は対称正定値行列である。

極分解は 「回転」 と 「伸縮」 に分けて考える方法であり、 リーマン多様体最適化でも現れる。

最適化との関係

線形代数は、最適化において勾配、ヘッセ行列、制約条件、ラグランジュ乗数などを扱うための基礎である。 特にヘッセ行列の正定値性は、局所最小性や凸性を判断する上で重要である。
