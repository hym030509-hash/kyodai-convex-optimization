凸関数

凸最適化の中心となる関数クラスです。

定義

関数 \(f:C\to\mathbb{R}\) が凸関数であるとは、凸集合 \(C\) 上で任意の \(x,y\in C\) と \(\theta\in[0,1]\) に対して

\[ f(\theta x+(1-\theta)y) \le \theta f(x)+(1-\theta)f(y) \]

が成り立つことをいう。

一次条件

\(f\) が微分可能な凸関数であるとき、任意の \(x,y\) に対して

\[ f(y) \ge f(x)+\nabla f(x)^\top (y-x) \]

が成り立つ。これは、接平面が関数の下側から支えることを意味する。

二次条件

\(f\) が二階微分可能であるとき、\(f\) が凸関数であることは

\[ \nabla^2 f(x)\succeq 0 \]

がすべての \(x\) で成り立つことと対応する。

狭義凸関数

関数 \(f:C\to\mathbb{R}\) が狭義凸関数であるとは、 任意の異なる \(x,y\in C\) と\(\theta\in(0,1)\) に対して

\[(\theta x+(1-\theta)y)<\theta f(x)+(1-\theta)f(y)\]

が成り立つことである。 凸関数の不等号が厳密になったものと考えられる。

例：\[ f(x)=x^2 \]は狭義凸関数である。

最適化で重要な理由

凸関数を凸集合上で最小化する問題では、局所最適解が大域最適解になる。 そのため、凸性は最適化問題を扱いやすくする非常に重要な性質である。

強凸関数

ある定数 \(m>0\) が存在して

\[ f(y) \ge f(x) + \nabla f(x)^\top (y-x) + \frac{m}{2}\|y-x\|^2 \]

が成り立つとき、 \(f\) を \(m\)-強凸関数という。

強凸関数は狭義凸関数よりさらに強い概念であり、 最小解の一意性を保証する。

例： \[ f(x)=x^2 \] は強凸関数である。

一方、 \[ f(x)=x^4 \] は狭義凸であるが、 強凸ではない。

準凸関数

関数 \(f:C\to\mathbb{R}\) が準凸関数であるとは、 任意の \(x,y\in C\) と \(\theta\in[0,1]\) に対して

\[ f(\theta x+(1-\theta)y) \le \max\{f(x),f(y)\} \]

が成り立つことである。

凸関数なら必ず準凸関数であるが、 準凸関数だからといって凸関数とは限らない。

例： \[ f(x)=x^3 \] は凸関数ではないが、 単調増加であるため準凸関数である。

凸性の比較

種類 関係 例
凸関数 基本概念 x²
狭義凸関数 凸関数より強い x²
強凸関数 狭義凸より強い x²
準凸関数 凸より弱い x³

関係は \[ \text{強凸} \Rightarrow \text{狭義凸} \Rightarrow \text{凸} \Rightarrow \text{準凸} \] である。
